⚡ QUICK START GUIDE ⚡

1️⃣  ADD YOUR ACCOUNTS
   - Open: reporter_config/accounts.txt
   - Format: api_id,api_hash,phone_number,password
   - Example: 12345678,abcdef1234567890,+1234567890,mypassword

2️⃣  ADD USER TARGETS WITH MULTIPLE METHODS
   - Open: reporter_config/ban.txt
   - Format: username:method1,method2,method3 OR username:all
   - Examples:
     * @baduser:1,3,6       → 3 methods mein se random har cycle
     * @fakeuser:all        → Sab methods (1-10) mein se random
     * @troll:2,5,8         → In methods mein se koi ek
   - Methods: 1=Spam, 2=Other, 3=Violence, 4=Porn, 5=Copyright, 6=Fake, 7=Geo, 8=Drugs, 9=Details, 10=Child

3️⃣  RUN THE SCRIPT
   python reporter.py

4️⃣  KEY FEATURES ✨
   ✅ Har cycle mein DIFFERENT method use hoga
   ✅ Continuous automatic reporting
   ✅ Auto-removes banned accounts
   ✅ Configurable delays
   ✅ Add/remove targets while running

📊 EXAMPLE WORKFLOW:
   ban.txt: @baduser:1,3,6
   
   Cycle 1: @baduser → Method 1 (Spam)
   Cycle 2: @baduser → Method 6 (Fake)
   Cycle 3: @baduser → Method 3 (Violence)
   Cycle 4: @baduser → Method 1 (Spam)
   ... (randomly select from 1,3,6 har baar)

📝 NOTES:
   - Reports run in continuous cycles
   - Banned accounts auto-detected and removed
   - Use Ctrl+C to stop
